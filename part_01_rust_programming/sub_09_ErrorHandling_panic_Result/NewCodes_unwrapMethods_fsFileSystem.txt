------ something = Result<T, E> or something = Option<T> ------

something.unwrap()
=> returns T or E

something.unwrap_or_else(|error| -> {...})
something.unwrap_or_else(|_| -> {...})
=> Ok(T) -> returns T
   Err(error) -> execute the closure

something.unwrap_or_default()
=> Ok(T) -> returns T
   Err(error) -> returns T::default()

---------------- Result<T, E>.is_ok() | Result<T, E>.is_ok_and() | Result<T, E>.ok() ----------------

is_ok() checks whether the Result is Ok.
It returns a bool and does not extract the value.

is_ok_and() can filter successful Results based on the contained value.
let large_successful_results: Vec<&Result<i32, &str>> = results
    .iter()
    .filter(|result| result.as_ref().is_ok_and(|value| *value >= 20)) // keep valid values >= 20 only
    .collect();

ok() converts: Result<T, E> -> Option<T>
// Ok(value) -> Some(value) -> value
// Err(error) -> None -> discard

---------------- Result<T, E>.is_err() | Result<T, E>.is_err_and() | Result<T, E>.err() ----------------

Do similar things like ``Ok(T)`` cases but now for ``Err(error)``

------------------ fs: File System ------------------

use std::fs::{
    self,
    File
};

let file_result = File::open("hello.txt");
/*
 * ``File::open()`` returns a ``Result<T, E>`` Type
 * => Use ``match`` to handle
*/

let contents = fs::read_to_string("hello.txt");
(opens the file, creates a new String, reads the contents of the file, puts the contents into that String,
and returns it as ``Result<String, E>``)

let contents = fs::read_to_string("hello.txt").unwrap_or_default();
=> ``fs::read_to_string()`` returns ``Result<String, E>``
=> use ``.unwrap_or_default()`` to get the String if it succeeds,
                                                  else returns ``String::default()``
